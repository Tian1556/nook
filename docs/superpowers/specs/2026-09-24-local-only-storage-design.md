# Nook 本地存储设计

## 背景

Nook 是基于 Noty 1.9.2 制作的私人版本，只在当前 Mac 上使用。现有代码包含一套可选的 iCloud Drive 文件夹同步功能，会把笔记以未加密 Markdown 文件写入 iCloud。该能力不符合 Nook 的本地工具定位，也增加了设置项、后台定时任务和数据冲突处理成本。

## 决策

彻底移除 iCloud 同步能力。Nook 只使用现有的本地加密数据库保存笔记，不提供云同步入口、后台同步任务或云端文件读写。

## 数据边界

- 保留现有本地数据库及其中的全部笔记，不执行数据库迁移或重建。
- 不读取、修改或删除 iCloud Drive 中可能已经存在的 `Nook` 文件夹和文件。
- 删除功能后，Nook 不再创建 iCloud 文件夹，也不再把笔记导出到该文件夹。
- 普通的手动导入、导出功能不受影响。
- GitHub 代码仓库同步不受影响；本设计只涉及 App 内的 iCloud 数据同步。

## 产品与界面

- 从设置窗口移除“同步”标签及其状态、立即同步和在访达中显示等控件。
- 删除中英文同步文案。
- README 明确说明 Nook 是仅本地应用，数据保存在本机加密数据库中。

## 代码范围

- 删除 iCloud 文件夹访问、文档序列化、同步索引、同步决策和同步执行代码。
- 删除应用启动、终止和设置变化时触发同步的调用。
- 删除仅服务于 iCloud 同步的设置键与时间间隔。
- 删除同步专用测试，并从测试入口移除相关调用。
- 不重构与本任务无关的编辑器、窗口、快捷键或导入导出代码。

## 兼容处理

旧版本可能在用户偏好中留下 `cloudSyncEnabled`，也可能在应用支持目录中留下同步索引。这些无害的孤立数据不主动清理，避免为了清理而增加一次性迁移代码或误删数据。新版本不会读取它们。

## 验证标准

1. 设置窗口不再显示同步标签。
2. 源码和资源中不存在可执行的 iCloud、CloudKit 或 ubiquity 访问逻辑。
3. 应用启动、编辑和退出过程中不会访问 iCloud Drive。
4. 编辑器与持久化测试通过。
5. Release 版本能够构建并启动，本地已有笔记仍可读取和保存。
6. README 不再宣称支持 iCloud 同步。

## 发布方式

修改完成后提交到 `main` 并推送至私人仓库 `Tian1556/nook`。当前 `nook-v1.9.2` 标签继续保留，作为移除同步前的可恢复基线；新改动不移动该标签。
