# 当前便签另存为 Markdown 设计

## 背景

Nook 已支持把全部便签批量导出为 Markdown，但现有入口只能选择目标文件夹并一次生成多份文件。用户需要把正在查看的单篇便签另存为一个可独立使用的 Markdown 文件，并在便签内通过按钮、右键菜单或快捷键快速调用。

## 目标

- 将当前便签另存为一个 `.md` 文件。
- 使用 macOS 标准保存面板选择文件名和保存位置。
- 在便签顶部、正文右键菜单和便签内快捷键提供一致入口。
- 导出图片到同目录资源文件夹，使 Markdown 离开 Nook 后仍可显示图片。
- 复用现有 Markdown 与任务清单转换规则，不改变原便签和现有批量导出行为。

## 非目标

- 不建立便签与外部 Markdown 文件之间的持续同步。
- 不记忆上次导出位置，也不在正文变化后自动覆盖外部文件。
- 不注册系统全局保存快捷键。
- 不修改现有的“导出全部便签”功能。

## 交互设计

当前便签的所有展示形态保持一致：便签栏展开视图、独立悬浮便签和便签库详情页均提供顶部导出按钮。按钮使用系统导出图标，帮助文字为“另存为 Markdown  ⌘⇧S”。

正文右键菜单增加“另存为 Markdown…”。顶部按钮、右键菜单和快捷键调用同一个单篇导出入口。

默认快捷键为 `⌘⇧S`，仅在 Nook 当前便签窗口内生效，并加入“设置 → 快捷键 → 便签内”以便修改和参与重复快捷键检查。每次触发都打开标准“另存为”窗口。

保存面板默认文件名按以下顺序生成：

1. 自定义便签标题；
2. 正文派生标题；
3. 本地化的“未命名便签”。

文件名移除文件系统不允许的字符并限制长度，扩展名固定为 `.md`。用户取消保存时不产生任何文件或文件夹。

## Markdown 内容

导出前先刷新当前便签的本地持久化状态，再读取最新内容。

- 有自定义标题时，以 `# 标题` 开头；正文已以相同一级标题或相同首行开头时不重复添加。
- 没有自定义标题时，沿用现有单篇 Markdown 渲染规则：若正文首行不是 Markdown 标题、任务项或图片，则提升为一级标题。
- Nook 任务标记转换为标准 Markdown `- [ ]` 和 `- [x]`。
- 其他 Markdown 原文、空行和正文顺序保持不变。

单篇导出与批量导出共享基础正文转换函数，避免任务与标题规则随时间漂移；单篇导出的自定义标题包装和图片改写保持独立，不改变批量导出的输出。

## 图片资源

如果便签没有图片，只生成 `.md` 文件。如果存在图片，则在 Markdown 同目录创建 `<Markdown文件名>_assets` 文件夹，并把内部 `noty-img://` 标记改写为相对路径，例如：

```markdown
![image](项目记录_assets/550E8400-E29B-41D4-A716-446655440000.png)
```

- 保留图片的宽度信息时，继续使用 Markdown 可读的替代文本，不写入 Nook 私有链接。
- 图片文件使用稳定的图片 ID 和根据文件内容识别的扩展名。
- 同一张图片在正文中出现多次时只复制一次。
- 重复导出时可覆盖同 ID 的 Nook 图片，但不删除资源文件夹中的其他文件，也不清理已经不再引用的旧图片，避免误删用户放入的内容。
- 如果资源文件夹路径已被普通文件占用，或任一引用图片缺失、不可读、不可写，则本次导出失败并显示错误。

## 写入与错误处理

导出流程为：

1. 用户在保存面板确认目标 `.md` 路径；
2. 生成 Markdown 并收集去重后的图片清单；
3. 创建或验证资源文件夹，复制并验证所有图片；
4. 最后以原子方式写入 Markdown 文件；
5. 成功后在 Finder 中定位该文件。

Markdown 最后写入，确保图片失败时不会留下一个引用不完整资源的新文档。覆盖已有 Markdown 由标准保存面板确认。失败时显示本地化错误信息，并保留已有 Markdown 文件不变；已经成功复制但最终未被引用的图片可以保留，因为自动清理存在误删用户文件的风险。

## 组件边界

- `Transfer`：提供单篇 Markdown 保存入口，负责保存面板、正文渲染、图片规划、文件写入和错误提示。
- `ImageStore`：提供只读的导出图片载荷，包括原始数据和可靠扩展名；不负责选择路径或生成 Markdown。
- `NoteTextView` / `TaskTextView`：接收“导出当前便签”回调并把它挂到正文右键菜单，不直接访问文件系统。
- 便签栏、悬浮便签和便签库：各自提供顶部按钮并传入当前便签；各窗口的本地键盘监听读取同一份可配置快捷键。
- `Settings` / `SettingsWindow`：保存和编辑便签内导出快捷键，默认值为 `⌘⇧S`。

## 验证标准

1. 三种入口均导出当前便签，而不是全部便签。
2. 保存面板默认使用安全的便签标题和 `.md` 扩展名。
3. 自定义标题只出现一次；无标题便签沿用现有首行标题规则。
4. 普通文本、Markdown 和任务清单导出正确。
5. 无图便签只生成 Markdown；有图便签生成资源文件夹和可用相对链接。
6. 单图、多图和重复图片均正确，重复图片只写一份。
7. 图片缺失、目标不可写、资源路径冲突和用户取消均得到安全处理。
8. 已有 Markdown 在图片准备失败时不被覆盖。
9. `⌘⇧S` 默认有效、可自定义，并能检测与其他 Nook 快捷键重复。
10. 原有批量导出、导入、图片、快捷键、持久化和本地模式测试继续通过。
